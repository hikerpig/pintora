# Architecture Decision Records

ADRs capture decisions that are non-obvious from the code and the surrounding context that motivated them. Each ADR is immutable once accepted; supersede by adding a new ADR that references the old one.

## Creating a new ADR

1. Copy [`template.md`](template.md) to `NNNN-short-slug.md`, where `NNNN` is the next zero-padded integer.
2. Fill in every section.
3. Add an index row above.
4. Open a PR; reviewers focus on `Context` and `Consequences`.
