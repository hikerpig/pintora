---
title: C4 Diagram
---

C4 diagrams describe software architecture using people, software systems, containers, components, and relationships.

Pintora's C4 diagram syntax is macro-first. It is intended to be familiar to Mermaid C4 and C4-PlantUML users, while using Pintora's dagre-based automatic layout.

## System Context

```pintora play
C4Context
title: System Context

Person(customer, "Customer", "Uses online banking")
System(banking, "Internet Banking System", "Allows customers to view accounts")
System_Ext(email, "E-mail System", "Sends notifications")

Rel(customer, banking, "Uses", "HTTPS")
Rel(banking, email, "Sends e-mail", "SMTP")
```

## Container

```pintora play
C4Container
title: Internet Banking - Containers

Person(customer, "Customer", "A retail banking customer")
System_Boundary(banking, "Internet Banking System") {
  Container(web, "Web Application", "React", "Delivers the single-page app")
  Container(api, "API Application", "Spring Boot", "Handles business requests")
  ContainerDb(db, "Database", "PostgreSQL", "Stores account data")
}
System_Ext(email, "E-mail System", "Sends notifications")

Rel(customer, web, "Uses", "HTTPS")
Rel(web, api, "Calls", "JSON/HTTPS")
Rel(api, db, "Reads/Writes", "JDBC")
Rel(api, email, "Sends messages", "SMTP")
```

## Component

```pintora play
C4Component
title: API Application - Components

Container_Boundary(api, "API Application") {
  Component(controller, "Account Controller", "TypeScript", "Handles HTTP requests")
  Component(service, "Account Service", "TypeScript", "Applies business rules")
  ComponentDb(repository, "Account Repository", "TypeScript", "Reads account data")
}

Rel(controller, service, "Calls")
Rel(service, repository, "Reads")
```

## Dynamic

```pintora play
C4Dynamic
title: Sign-in Flow

Container(web, "Web Application", "React")
Container(api, "API Application", "Node.js")
ContainerDb(db, "Database", "PostgreSQL")

RelIndex(1, web, api, "Submits credentials", "JSON/HTTPS")
RelIndex(2, api, db, "Reads user record", "SQL")
RelIndex(3, api, web, "Returns session", "JSON/HTTPS")
```

## Tag Styles And Legends

```pintora play
C4Container
title: Styled Container Diagram

AddElementTag("critical", $bgColor="#ffdddd", $fontColor="#550000", $borderColor="#cc0000", $shape=RoundedBoxShape(), $legendText="Critical element")
AddRelTag("async", $textColor="#003366", $lineColor="#0066cc", $lineStyle=DashedLine(), $legendText="Async call")

Container(api, "API Application", "Node.js", $tags="critical")
ContainerQueue(events, "Domain Events", "Kafka")
Rel(api, events, "Publishes", $tags="async")

UpdateElementStyle(api, $borderColor="#003399")
UpdateRelStyle(api, events, $lineColor="#0066cc", $textColor="#003366")
UpdateLayoutConfig(3, 1)

SHOW_LEGEND()
```

## Supported Macros

| Category      | Macros                                                                                                                    |
| ------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Entries       | `C4Context`, `C4Container`, `C4Component`, `C4Dynamic`, `C4Deployment`, `c4Diagram`                                       |
| People        | `Person`, `Person_Ext`                                                                                                    |
| Systems       | `System`, `System_Ext`, `SystemDb`, `SystemDb_Ext`, `SystemQueue`, `SystemQueue_Ext`                                      |
| Containers    | `Container`, `Container_Ext`, `ContainerDb`, `ContainerDb_Ext`, `ContainerQueue`, `ContainerQueue_Ext`                    |
| Components    | `Component`, `Component_Ext`, `ComponentDb`, `ComponentDb_Ext`, `ComponentQueue`, `ComponentQueue_Ext`                    |
| Boundaries    | `Boundary`, `Enterprise_Boundary`, `System_Boundary`, `Container_Boundary`, `Deployment_Node`, `Node`, `Node_L`, `Node_R` |
| Relationships | `Rel`, `BiRel`, `Rel_U`, `Rel_Up`, `Rel_D`, `Rel_Down`, `Rel_L`, `Rel_Left`, `Rel_R`, `Rel_Right`, `Rel_Back`, `RelIndex` |
| Styling       | `AddElementTag`, `AddRelTag`, `UpdateElementStyle`, `UpdateRelStyle`, `UpdateLayoutConfig`                                |
| Legends       | `SHOW_LEGEND`, `SHOW_DYNAMIC_LEGEND`, `Legend`                                                                            |

## Arguments

Element macros use positional arguments:

```txt
Container(alias, "Label", "Technology", "Description")
```

Named arguments can be used for common optional fields:

```txt
Person(customer, "Customer", $descr="Uses the service", $tags="person,external", $link="https://example.com")
```

Relationship macros use:

```txt
Rel(sourceAlias, targetAlias, "Label", "Technology")
```

Dynamic relationship macros use:

```txt
RelIndex(index, sourceAlias, targetAlias, "Label", "Technology")
```

Tag style declarations use:

```txt
AddElementTag(tagStereo, ?bgColor, ?fontColor, ?borderColor, ?shadowing, ?shape, ?sprite, ?techn, ?legendText, ?legendSprite)
AddRelTag(tagStereo, ?textColor, ?lineColor, ?lineStyle, ?sprite, ?techn, ?legendText, ?legendSprite)
```

### Style Updates

Direct style update macros use:

```txt
UpdateElementStyle(elementName, ?bgColor, ?fontColor, ?borderColor, ?shadowing, ?shape, ?sprite, ?techn, ?legendText, ?legendSprite)
UpdateRelStyle(from, to, ?textColor, ?lineColor, ?offsetX, ?offsetY)
UpdateLayoutConfig(?c4ShapeInRow, ?c4BoundaryInRow)
```

`UpdateElementStyle` and `UpdateRelStyle` are applied after tag styles for matching elements and relationships.
`UpdateLayoutConfig` is parsed as Mermaid compatibility metadata, but Pintora still uses dagre automatic layout.
`offsetX` and `offsetY` on `UpdateRelStyle` are parsed but not rendered yet.

Rendered style helpers include `RoundedBoxShape()`, `SolidLine()`, `DashedLine()`, `DottedLine()`, and `BoldLine()`. `EightSidedShape()` is parsed for compatibility, but currently renders as the default box shape.

Generated legends are shown when `SHOW_LEGEND()`, `SHOW_DYNAMIC_LEGEND()`, or `Legend` is present. Only tag declarations that are used by elements or relationships are included.

Element tag declarations currently affect:

- `bgColor`
- `fontColor`
- `borderColor`
- `RoundedBoxShape()`
- `techn` when the element does not already define technology

Relationship tag declarations currently affect:

- `textColor`
- `lineColor`
- `SolidLine()`
- `DashedLine()`
- `DottedLine()`
- `BoldLine()`
- `techn` when the relationship does not already define technology

If an element or relationship has multiple tags, later tags in `$tags` override earlier tags for the same style field.

## Layout Notes

Pintora uses dagre automatic layout for C4 diagrams. The result may differ from PlantUML and Mermaid layouts.

Direction-specific relationship macros such as `Rel_R` are parsed as relationship metadata. They do not force exact manual placement.

Generated legends are laid out to the right of the diagram. They are not displayed unless a legend macro is present.

## Unsupported C4-PlantUML Features

Pintora C4 does not run PlantUML preprocessing. These features are not part of the current implementation:

- `!include`, `!define`, procedures, and macro expansion
- Sprites and icon libraries
- Shadow rendering for tag declarations
- Eight-sided element shape rendering
- Manual row layout from `UpdateLayoutConfig`
- Relationship label offsets from `UpdateRelStyle`
